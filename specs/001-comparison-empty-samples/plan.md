## Summary

在现有 `prototype-v11.js` 的两期对比显示层区分无样本、有效零值和不可计算比例，
复用报表筛选、`totals()`、有效修订口径和现有 SVG 折线，不改变数据状态及统计公式。

## 研究决策与暂时性实施规划

| 决策 | 理由 | 已考虑的其他方式 |
| --- | --- | --- |
| 在对比显示层判断 N=0 | 保持 totals() 的统计含义，避免影响其他页面 | 改 totals() 为全部 null 会波及统计和导出 |
| 无样本 N 显示 0 并注明原因，其他指标显示 — | 企业数是有效样本计数，岗位指标没有观测基础 | 全部显示 0 容易被误读为实际岗位清零 |
| 折线允许传入各点缺失原因 | 无样本与零分母能分别解释，趋势调用继续兼容 | 用同一“缺失”标签无法解释有样本的零分母 |
| 有效 D=0 的柱宽为 0 | 最小宽度会制造有变化的印象；文字仍显示 0 人 | 保留最小 2% 宽度会误导 |
| 开发辅助数据验证 B=0 | 示例本来没有这一合法边界，不修改业务种子 | 新增演示场景扩大产品入口和文件范围 |

## 数据与显示约定

继续使用 `comparisonData()` 输出两组有效报表，再用 `totals()` 计算 N/B/E/D/L/R。
共同样本使用较晚期资料快照，独立样本用各期快照。
`effective()` 依据人数口径选原始或已生效修订数据。
N=0 时图表值使用 null；N>0 且 R=null 时原因是不可计算。
其他数值中的 0 仍为有效观测，不用真假判断过滤零值。
分组表格和总表复用同一显示函数；变化柱忽略缺样本，缩放只受有效变化影响。

## 界面与交互

沿用省级“两期对比”的月份、样本方式、地区、性质、行业、指标和人数口径控件。
点击“应用分析条件”后查看结果。无样本期显示“无有效样本”，不画变化柱；
比例不能计算时在对应位置显示“不可计算”。
本项不修改应用条件按钮的既有状态处理方式。
