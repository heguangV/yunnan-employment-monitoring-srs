# Feature Specification: 两期对比的缺样本与零值显示

**Feature Branch**: `codex/spec-kit-pilot`
**Created**: 2026-10-07
**Status**: 已实施并通过本项验收（2026-10-07）
**Input**: 在现有需求演示原型中实践 Spec Kit，修正两期对比把缺少有效样本呈现为零岗位的问题。

## User Scenarios & Testing

### User Story 1 - 识别没有有效样本的调查期 (Priority: P1)

省级用户选择两个不同调查期及共同或独立样本，查看六指标表格、分组表格、
折线图和岗位变化柱状图，能够明确识别哪些调查期或分组没有有效报表，
不会把未上报误认为零岗位或岗位清零。

**Why this priority**: 错把缺样本当零值会造成错误的就业变化判断。
**Independent Test**: 用现有演示数据选择 2026-07 与 2026-08，即可分别观察共同、独立样本结果。

**Acceptance Scenarios**:

1. **Given** 七月没有有效报表、八月有甲企业，**When** 选择独立样本，
   **Then** 七月企业数为“0（无有效样本）”，其他五项显示“—”，
   七月图中有“无有效样本”提示，没有数据点和变化柱；八月保留真实结果。
2. **Given** 两期没有共同企业，**When** 选择共同样本，
   **Then** 两期都显示无有效样本，没有零值折线或变化柱，分组区域提示调整样本方式或月份。
3. **Given** 选择八月与九月、独立样本，某分组仅九月有企业，
   **When** 查看地区、性质或行业分组，**Then** 该组八月为缺样本，九月为实际指标。
4. **Given** 条件筛选后两期都没有企业，**When** 应用分析条件，
   **Then** 表格和图表一致呈现无有效样本，不沿用筛选前的值。

### User Story 2 - 区分实际零变化与不可计算比例 (Priority: P1)

省级用户看到真实零值时仍能判断其为有效报表统计结果；
当存在有效报表但建档岗位总数为零时，能够判断变化比例不可计算。

**Why this priority**: “没有报表”“有报表且结果为零”“除数为零”是三种不同含义。
**Independent Test**: 在开发者演示数据中分别设置一份 B=E=100 和一份 B=E=0 的有效报表。

**Acceptance Scenarios**:

1. **Given** 有有效报表且 B=E=100，**When** 查看岗位变化，
   **Then** 显示 D=0、L=0、R=0.00%，折线保留零值数据点，变化柱不人为增加可见宽度。
2. **Given** 有有效报表且 B=E=0，**When** 查看变化比例，
   **Then** N 大于零，B/E/D/L 都显示实际零值，R 显示“不可计算”，
   比例折线该期标注“不可计算”且不连接有效数据点。

### Edge Cases

- 两期选择顺序反转时，缺样本提示跟随对应月份。
- 同期选择仍由既有表单校验拒绝。
- 共同样本缺失、独立样本缺失和筛选导致缺失使用相同的显示规则。
- 修订有效口径中出现零建档岗位时，按该口径判断比例是否可计算。
- 有效期的负变化继续显示负数，缺样本不参与柱状图缩放。

## Requirements

### Functional Requirements

- **FR-001**: 没有省审通过且未删除报表的调查期或分组，企业数明确显示为零并注明无有效样本；岗位类指标和比例用“—”表示缺失。
- **FR-002**: 无有效样本的折线位置必须显示提示，不绘制数据点，也不跨缺失位置连线；变化柱不得把缺失显示为 0 人。
- **FR-003**: 有有效样本时，实际零值必须保留；零岗位变化不得绘制人为最小宽度的变化柱。
- **FR-004**: 有样本但建档岗位总数为零时，变化比例必须显示“不可计算”，比例图对应位置同样标明不可计算。
- **FR-005**: 六指标总表、地区/性质/行业分组表、折线和变化柱必须使用同一筛选结果及人数口径。
- **FR-006**: 保持两期不同校验、默认共同样本、独立样本按各期快照分组、共同样本按较晚期快照分组的行为。

### Key Entities

- **有效样本**：对应月份省级审核通过且未删除的企业报表；继续受地区、性质、行业和样本方式筛选。
- **六指标**：N 企业数；B 建档岗位之和；E 调查岗位之和；D=E−B；
  L 为逐企业减少岗位的合计；R=(E−B)/B×100%，B=0 时不可计算。
- **显示状态**：无有效样本、有效数值（含零）、不可计算比例。缺失显示不改变底层报表数据。

## Success Criteria

### Measurable Outcomes

- **SC-001**: US1 四个场景中，所有无有效样本位置均有提示，误导性零值点和变化柱数量为零。
- **SC-002**: US2 两个场景中，实际零值与不可计算比例可从表格及图表直接区分，标记与指标含义全部一致。
- **SC-003**: 八月甲 B=100/E=90 时显示 N=1/B=100/E=90/D=−10/L=10/R=−10.00%；六月甲 B=100/E=96 时 R=−4.00%，三个分组维度不改变总指标。
- **SC-004**: 在现有离线打开方式下即可完成两个调查期和样本方式的切换，无需新增服务。

## Assumptions

本项细化 SRS V1.1 的 FR-17、3.8 节及 AC-07，业务基线仍为：
缺失人数不能当零，图表与表格一致，无样本不能绘制误导性图形。
当前交付是需求演示原型；实际后台和国家交换不是本项交付内容。

## 暂时性实施规划

无样本的企业数“0”表示命中有效企业数量，附加“无有效样本”避免歧义；
其余五项用“—”表示没有可用于统计的岗位样本。
任何图表指标在该期无样本时均留空并说明原因。
有样本的零分母比例使用“不可计算”，其余指标正常显示。
无需其他部门提供额外资料。
