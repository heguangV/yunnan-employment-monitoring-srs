## 直接体验

用 Chrome 或 Edge 打开 `项目交互原型/index.html`，点击“开始完整业务演示”，依次体验备案、企业填报、市审、省审、统计和模拟报送。顶部可切换角色和演示场景。原型使用 HTML、CSS 和原生 JavaScript，无需安装依赖。

示例企业和账号为合成数据；业务状态刷新后重置，页面方向记录可以本地保存。模拟登录、国家交换等页面演示不代表正式后台、认证或真实接口已经完成。

## 日常维护与文件收纳

修改需求时同步维护 `需求文档/需求规格书内容.md`、Typst 文档源、原型和页面映射。所有独立 Typst 文档引用 `styles/bit-format.typ`，不复制样式。

按用途直接保存最终文件：需求文档放入 `需求文档/`，计划放入 `项目计划/`，课程材料放入 `课程资料/`，项目说明放入 `项目说明/`。项目内不保存旧草稿、重复导出、一次性生成脚本、审核脚本、渲染预览、检查截图、缓存或依赖。

临时验证、提取和生成工作使用系统临时目录中的独立任务目录；结束后仅将确认的最终文件收纳到项目内。`.gitignore` 只是 Git 保护，不替代实际目录清理。2026-10-14 的整理已将既有过程文件移出项目，并保留当前交付和必要可编辑源；旧版本和过程文件的临时保全目录也位于项目外。

本次收纳验证：最终 XLSX、MPP、PDF 搬移前后的文件哈希一致，Markdown 链接全部有效，原型页面及交互源码未修改。当前 PDF 与迁移后重新编译的 53 页文档逐页文字一致；Excel 的六个工作表可读取，Project 已从新位置打开，外部 Python 的 Spec Kit 入口可用。保留 14 个课程录像和 208 张平台课件图片，项目内无缓存、核验副本或一次性脚本残留。

## 编译当前文档

在项目根目录运行已安装的 Typst：

```powershell
typst compile --root . "需求文档/云南省企业就业失业数据采集系统_SRS_V1.2.typ" "需求文档/云南省企业就业失业数据采集系统_SRS_V1.2.pdf"
```

验证编译或版面预览时，将输出路径改为项目外的临时目录；只在确认交付时写入目标 PDF。一次性文档生成与打包脚本已移出项目，不再作为目录内构建入口。
