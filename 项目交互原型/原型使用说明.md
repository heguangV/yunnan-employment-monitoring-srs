# 云南省企业就业失业数据采集系统 · 需求演示原型 V1.1

基线：SRS V1.1。更新日期：2026年10月7日。

本原型让初次接触项目的开发人员直接理解业务目标、页面布局、操作顺序和异常反馈，并记录需求方向。页面中的企业、地区、账号、人数和回执均为合成示例。无需另外阅读工作说明书即可完成下面的演示。

## 打开方法

解压后用 Chrome 或 Edge 双击 `index.html`。保持 `index.html`、`prototype.css`、`prototype.js`、`prototype-v11.js` 在同一目录。无需安装、联网或真实账号。

首次打开从“项目导览”开始。点击“开始完整业务演示”，按顶部八步操作。未完成必要提交或审核时，“下一步”会提示应完成的动作。

顶部角色切换用于体验不同身份；场景切换和“重置演示”恢复示例数据。业务变更只存在本次浏览器会话，刷新即重置。页面评审记录单独保存在浏览器本地，可导出 Markdown。

## 项目目标与角色

采集企业资料、建档人数 B、调查人数 E 和减少原因，经市、省两级审核，形成可追踪、可复算的月报、统计和报送批次。岗位变化 D=E−B；岗位减少 L 按每家企业的 max(B−E,0) 累加；变化比例 R=(ΣE−ΣB)/ΣB，分母为零显示不可计算。

| 身份 | 主要工作与范围 |
| --- | --- |
| 企业 | 维护自身资料、提交月报、查看历史和上级通知；无导出 |
| 市级审核 | 审核本市企业月报；通过自动转省级；无导出 |
| 省级业务 | 全省备案、省审、查询、统计、修订、补报及国家报送；默认同时具备账号、角色、调查期、字典、监控和三类导出 |
| 技术管理 | 维护账号和配置；不隐含省级业务权；账号导出须显式授予 |

系统不建立个人失业档案，不计算个人失业率，不处理社保核算。

## 先走通八步主流程

| 步骤 | 页面与操作 | 应看到的结果 |
| --- | --- | --- |
| 1 | 省级用户管理：查看账号与企业归属，点下一步 | 企业甲账号已预置，可另建示例账号 |
| 2 | 企业资料：核对字段，提交备案 | 待备案，提交内容只读 |
| 3 | 省级备案：查看企业甲并通过 | 企业获得月报填报入口 |
| 4 | 企业填报：B100、E80、减少主要项及其他原因有值，提交 | 提交v1冻结，待市审 |
| 5 | 市级审核：查看并通过 | 自动进入省级待审 |
| 6 | 省级审核：查看并通过 | 纳入统计与报送 |
| 7 | 月度统计：查看六指标 | 甲100/80、乙50/60；N2、B150、E140、D−10、L20、R−6.67% |
| 8 | 国家报送：创建冻结批次、发送、查看详情 | 模拟接收成功和逐条模拟回执 |

## 场景与数据

| 场景 | 初始状态 | 用途 |
| --- | --- | --- |
| 日常填报 | 甲已备案、9月草稿；乙9月已省审 | 校验、退回、重提、资料变更 |
| 首次备案 | 甲尚未备案、无历史月报 | 八步完整链路 |
| 统计复算 | 甲乙9月均已省审 | 双口径、取样、两期对比、删除恢复 |
| 过期补报 | 演示时间10月12日，默认窗口关闭 | 72小时补报与到期 |
| 报送异常 | 甲乙均已省审 | 部分拒绝、未知回执、认证失败、REAL未配置 |

所有场景都有已备案但未报的企业丙：属于市甲、乡村，账号 qy_c 停用。它计入备案取样，不计入有效上报人数。除首次备案外，甲有6月100/96、8月100/90历史记录，7月缺失。默认演示时钟为2026年10月6日10:00（上海时区），填报操作固定9月。

## V1.1重点演示路径

| 需求方向 | 操作 | 可核对结果 |
| --- | --- | --- |
| 企业字段 | 申请资料变更，修改组织机构代码；输入非法名称或传真 | ORG9固定；代码1至9位字母数字、转大写、唯一；姓名限中文英文及内部空格；传真必须带区号固话 |
| 原因选填 | 次要原因单独选值，第三说明单独填写后提交 | 可重复、可跳项、无需配对；仅E小于B时减少类型、主要原因及主要说明必填；其他原因总是必填，可填“无” |
| 退回重提 | 市审或省审空备注退回，再由企业提交 | 空备注显示“未填写备注”；重提回市审；备案退回仍要求理由 |
| 待审修订 | 市审通过后在省级另存修订 | 待省审可保存，生效按钮不可用；省审通过后才能生效；重提版本不套用旧修订 |
| 查询 | 综合查询账号／报表页签，组合13条件 | 默认账号包括省市、停用、未报企业；账号日期按创建日、报表按提交日；月季冲突报错；清除恢复全部 |
| 备案档案 | 选4月、9月，查看丙 | 4月无备案；9月3家；未报企业不丢失；详情使用对应生效版本 |
| 取样分析 | 统计复算场景，备案口径／有效上报9月，再筛市甲 | 备案2:1，66.67%:33.33%；上报1:1；筛选后重算分母，图表数量一致 |
| 两期对比 | 8月对9月，切共同／独立，按地区／性质／行业分组；再选7月对8月 | 共同仅甲；独立9月增加乙；无样本期N为0并注明原因，其他指标为—，图中无点无柱；有样本的0正常显示，0分母比例不可计算 |
| 连续趋势 | 6至9月或季度快捷筛选 | 6月−4%、8月−10%；7月断线，缺失不补0；季度只选择月份 |
| 通知范围 | 省级甲／乙下拉切换，发布、管理、删除，再切企业 | 省级仅本人；企业和市级可读两者；本人管理保留删除记录；单位名按发布时账号冻结 |
| 账号与角色 | 新建、修改、角色分配、删除角色 | 删除角色解除关联但保留用户；无角色状态可见；本人已有正式提交的账号禁止删除 |
| 调查期 | 新增10月，修改窗口，再尝试重复月份 | 新增与编辑可用；月份唯一，开始早于截止；9月窗口修改即时影响9月填报 |

修订复算：甲E从80改85，保存后统计不变；生效后修订口径E145、D−5、L15、R−3.33%，原始口径与旧批次仍为140。撤销恢复上一有效版本；编号递增。

异常交换：选择“部分拒绝”建批发送，修订失败企业后只补发失败项；“结果未知”必须先查回执；被未知或发送中批次引用的报表禁止删除。REAL显示未配置，不显示模拟成功。

删除恢复：通过影响预览、理由和二次确认执行逻辑删除；统计退出、旧批次不改；30日恢复窗口内可恢复，恢复不自动报送。

## 记录需求方向

每页顶部“页面评审说明”给出需求编号、关键规则和方向记录入口。选择沿用或调整，并写明“在哪个页面、哪个操作、希望看到什么结果”。导览中的“方向记录”可查看和导出。无需其他部门签署，不会向任何人发送消息。

## 演示边界与验证

可交互演示的是页面、表单、状态迁移、筛选、图表、通知和管理操作。真实认证、服务端权限及即时会话撤销、数据库事务、XLSX文件生成、运行指标采集、国家交换适配、性能和备份恢复需要在正式系统实现和验收。角色切换是演示控制，不能作为权限安全证明。

新增调查期演示配置增改，填报表单固定9月。地区JSON做结构校验预览，不持久导入；地区使用两市两县。查询只有少量样本，不模拟跨页大数据；连续分析最多24个月。浏览器刷新不保留业务变更。

国家交换AC-10A展示本地模拟方向；AC-10B真实适配、发送和实际接收凭据尚未执行，正式交付仍需满足。
