## 模型含义

当前包含 5 个参与者、32 个用例、32 个类、33 个实体；类关联 40 条、ER 联系 52 条、用例 include/extend 3 条。三类总图加 37 幅分组详图共 40 幅 SVG。普通参与者关联线另外计算，不计入 3 条用例语义关系。

2026-10-20 修订图形布局：节点按联系排布，联系编号和中文名嵌入各自路径的文字留白处；文字两侧的线段仍表示同一条关系。用例连线通过两侧通道避开无关椭圆；备案、联系与基准、交换接口实现分别成图，字典项和地区自关联提供独立详图。总图保留完整网络，跨线以留白区分；PDF 使用无关系交叉的详图，图形、图注与说明保持相邻。本轮只改表现层，模型源、43 项矩阵内容和业务基线未变。

最终建模报告 PDF 与模型源、图表和矩阵一同纳入版本管理，便于从仓库直接查看。`.gitignore` 仅对本目录这份最终 PDF 设置例外；临时编译结果和预览仍保存在项目外。

企业 UUID、备案申请、生效资料、加密联系记录、人数基准、月报聚合、原始提交、独立修订、审核决定、批次、条目及回执分别建模。UML 类图另列应用服务和交换接口；ER 另列关联实体及运行事实，不将两种图当成同一套表格。

ER 是逻辑分析模型，不是可以直接执行的数据库建表脚本。图形中的合并分类引用须按数据字典拆成具体地区、性质、行业及其版本的外键；跨对象一致性仍需事务与业务约束。ReportData、QueryFilters、AnalysisResult 是值对象，不为图表额外扩展业务范围。

## 后续维护

`模型.json` 是唯一权威模型及矩阵源。SVG、HTML、矩阵 Markdown 和 Typst 由维护工具同步生成；不直接修改生成文件后跳过模型源。该工具用于持续修订和再生成，属于必要开发源码；抽取、截图、核验脚本及其结果均在项目外临时目录。

每次需求、模型、实现或验收变化时，在对应需求行更新：

1. 来源、`usecases`、`classes`、`entities`、`wbs`、`owner` 和 `acceptance`；新增或撤销映射说明原因，稳定编号不复用。
2. `modelStatus`、`prototypeStatus`、`implementationStatus` 分别维护；实现证据填 `implementationEvidence`，记录代码版本、范围及位置。
3. `acceptanceItems` 中逐个 AC 的 `status`、`environment`、`evidence` 分开登记，再更新汇总 `acceptanceStatus`。证据应写实际步骤、结果、执行日期及可定位材料；没有证据不标通过。AC-10A 和 AC-10B 不能合并关闭。
4. `updatedAt`、`change` 和顶层 `history` 登记真实修订。普通派生映射修正不自动提升 SRS 或计划 CM；业务含义改变时按贡献指南同步受影响的 SRS、规格和 CR。

初始状态是“已建模，待评审／未登记正式实现证据／未验收”。原型方向来自现有页面映射，本次未重新测试既有业务原型。性能、安全、备份和真实交换均需实际证据；模型类与实体只是承载点。

矩阵 `owner` 是暂时性实施规划中的映射维护责任建议，使用现有 R01–R04；同一需求可能关联多项不同责任人的 WBS，不据此改写计划中各任务的原责任人、工时或排期。

## 重新生成

需要 Node.js、项目外安装的 `@viz-js/viz` 和 Typst。安装包不得放在仓库内；可复用本机已安装的外部依赖，也可在系统临时目录的独立工具目录安装。`VIZ_MODULE_PATH` 指向该库的 `dist/viz.js`，不把本机绝对路径写进项目源。

在项目根目录运行（先将环境变量设置为实际外部路径）：

```powershell
$env:VIZ_MODULE_PATH = '<项目外 @viz-js/viz 的 dist/viz.js 绝对路径>'
node '需求文档/面向对象建模/工具/维护模型.mjs'
typst compile --root . '需求文档/面向对象建模/面向对象建模报告.typ' '<项目外临时目录>/面向对象建模报告.pdf'
```

验证报告后，才将最终 PDF 收纳回本目录。重命名或删除详图时，将旧图移到项目外；不在本目录积累旧导出。维护工具会校验稳定需求、模型引用、AC/WBS、责任资源、证据槽位，以及总图与详图的关系覆盖。布局与打印分图规则维护在工具源码中；只调整表现层时不改模型或需求维护日期。

浏览文件没有远程依赖，生成后的 HTML 可直接打开。开发验证也可在项目根目录临时运行 `python -B -m http.server --bind 127.0.0.1`，但这不是离线阅读的前置条件。实际验证结果见 [本次计划](../../specs/004-object-oriented-modeling/plan.md)。
